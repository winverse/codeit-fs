# codeit-fs

코드잇 풀스택 과정의 기수별 학습 코드와 실습 프로젝트를 모아둔 아카이브 저장소입니다.

## 폴더 구성

- `codeit-fs-09`: 코드잇 풀스택 과정 09기 학습 코드와 실습 프로젝트
- `codeit-fs-11`: 코드잇 풀스택 과정 11기 학습 코드와 실습 프로젝트

## 저장소 안내

각 폴더에는 과정 중 다룬 예제, 실습, 미션, 완성본 코드가 기수별로 정리되어 있습니다.

하위 프로젝트는 원래 개별 저장소 또는 개별 프로젝트로 관리되던 코드이며, 현재 저장소에서는 한 곳에서 확인할 수 있도록 합쳐서 보관합니다.
