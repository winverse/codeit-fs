# codeit-fs

코드잇 풀스택 과정 09기와 11기를 위해 만든 학습 코드 아카이브입니다.

원하는 풀스택 학습 흐름을 만들기 위해 강의 교재를 전면 직접 작성했고, 이 저장소에는 그 교재와 연결되는 예제 코드, 예습 코드, 퀴즈 문제풀이 코드, 실습 코드, 미션 코드, 완성본 코드가 함께 정리되어 있습니다.

## 저장소 목적

- 풀스택 학습에 필요한 강의 교재와 실습 코드를 기수별로 보관합니다.
- 수업 전 개념을 미리 익힐 수 있는 예습 코드와 퀴즈 풀이 코드를 함께 정리합니다.
- 수업 중 따라 작성하는 예제 코드와 직접 해결해보는 실습/미션 코드를 구분해 참고할 수 있게 합니다.
- 같은 주제라도 스타터, 챌린지, 완성본 코드가 있는 경우 학습 단계별로 비교할 수 있도록 보관합니다.

## 폴더 구성

- `codeit-fs-09`: 코드잇 풀스택 과정 09기 학습 코드와 실습 프로젝트
- `codeit-fs-11`: 코드잇 풀스택 과정 11기 학습 코드와 실습 프로젝트

## 저장소 구조 안내

최상위 폴더는 기수별로 나뉩니다.

- `codeit-fs-09`에는 09기 수업에서 사용한 React, Router, Zustand, TanStack Router, Express, Prisma 등 프론트엔드와 백엔드 학습 코드가 들어 있습니다.
- `codeit-fs-11`에는 11기 수업에서 사용한 Git/GitHub, JavaScript DOM, React, Next.js, Express, Prisma, TypeScript, Jest, OAuth, 아키텍처, 객체지향, 배포/인프라 관련 코드가 들어 있습니다.

각 기수 폴더 안의 하위 폴더는 주제별 강의 또는 프로젝트 단위로 구성되어 있습니다. 예를 들어 라우팅, 상태 관리, 데이터 패칭, 인증, 데이터베이스, 테스트, 배포처럼 수업에서 다룬 주제별로 코드를 확인할 수 있습니다.

하위 프로젝트 중 일부는 원래 개별 저장소 또는 개별 프로젝트로 관리되던 코드입니다. 현재 저장소에서는 기수별 자료를 한 곳에서 확인할 수 있도록 합쳐서 보관합니다.

## 학습 자료 구성

각 주제는 필요에 따라 다음과 같은 형태의 자료를 포함합니다.

- 강의 내용을 설명하기 위해 직접 작성한 교재
- 교재 흐름에 맞춰 작성한 예제 코드
- 수업 전에 개념을 익히기 위한 예습 코드
- 퀴즈와 문제풀이 실습 코드
- 직접 구현해보는 챌린지/미션 코드
- 수업 후 참고할 수 있는 완성본 코드
