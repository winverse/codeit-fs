# 해설: 06. Programmatic Navigation 응용

## 🎯 챌린지 목표

`useNavigate` 훅을 사용하여, 폼 제출과 같은 실제적인 시나리오에서 프로그래밍 방식으로 페이지를 이동시키는 방법을 응용해봅니다.

## 📝 단계별 해설

`ContactPage.jsx` 파일의 `TODO` 주석을 따라 두 가지 핵심 기능을 구현합니다.

### **1단계: `useNavigate` 훅 호출**

첫 번째 `TODO`는 `useNavigate` 훅을 호출하여 페이지 이동을 제어하는 `navigate` 함수를 준비하는 것입니다.

```jsx
// ContactPage.jsx (수정 전)
import { useNavigate } from 'react-router';

export function ContactPage() {
  // TODO 1: useNavigate 훅을 호출하여 navigate 함수를 가져오세요.
```

강의에서 배운 대로, 컴포넌트 최상단에서 `useNavigate`를 호출합니다.

```jsx
// ContactPage.jsx (수정 후)
import { useNavigate } from 'react-router';

export function ContactPage() {
  const navigate = useNavigate();
```

### **2단계: 폼 제출 후 페이지 이동 구현**

두 번째 `TODO`는 `handleSubmit` 함수 내에서, 폼이 성공적으로 제출된 후 `/success` 경로로 이동하는 로직을 구현하는 것입니다.

```jsx
// ContactPage.jsx (수정 전)
const handleSubmit = (e) => {
  e.preventDefault();
  alert('문의가 성공적으로 제출되었습니다!');

  // TODO 2: "/success" 경로로 페이지를 이동시키세요.
  // HINT: replace: true 옵션을 사용하여, 뒤로가기 시 이 페이지로 돌아오지 않도록 합니다.
};
```

`alert` 창이 닫힌 후, `navigate` 함수를 호출합니다. `to` 인자로는 `/success`를, 두 번째 인자인 `options` 객체에는 `{ replace: true }`를 전달하여 문의하기 페이지가 브라우저 히스토리에 남지 않도록 합니다.

```jsx
// ContactPage.jsx (수정 후)
const handleSubmit = (e) => {
  e.preventDefault();
  alert('문의가 성공적으로 제출되었습니다!');

  navigate('/success', { replace: true });
};
```

## 🎉 최종 완성 코드

```jsx
// src/pages/Contact/ContactPage.jsx (최종)
import { useNavigate } from 'react-router';

export function ContactPage() {
  const navigate = useNavigate();

  const handleSubmit = (e) => {
    e.preventDefault();
    alert('문의가 성공적으로 제출되었습니다!');
    navigate('/success', { replace: true });
  };

  return (
    <div className="container">
      <div className="card">
        <h2>문의하기</h2>
        <form onSubmit={handleSubmit}>
          {/* ... form inputs ... */}
          <button type="submit" className="submit-button">제출</button>
        </form>
      </div>
    </div>
  );
}
```

## ✅ 확인하기

1.  **페이지 이동 확인**: "제출" 버튼을 누르면 `/success` 경로로 이동하며 성공 페이지가 나타납니다.
2.  **히스토리 확인**: 성공 페이지에서 브라우저의 "뒤로 가기" 버튼을 누르면, `/contact` 페이지가 아닌 `/` (홈페이지)로 이동합니다. `replace: true` 옵션이 정상적으로 작동한 것입니다.

이번 챌린지를 통해 강의에서 배운 `useNavigate`를 실제 폼 제출 로직에 응용하는 방법을 연습했습니다.
