## 🎉 **최종 완성 코드**

```jsx
import { Routes, Route, Link } from 'react-router';
import { HomePage } from './pages/HomePage';
import { AboutPage } from './pages/AboutPage';
import { ServicesPage } from './pages/ServicesPage';
import styles from './App.module.css';

export function App() {
  return (
    <div className={styles.app}>
      <header>
        <nav>
          <Link to="/">Home</Link>
          <Link to="/about">About</Link>
          <Link to="/services">Services</Link>
        </nav>
      </header>

      <main>
        <Routes>
          <Route path="/" element={<HomePage />} />
          <Route path="/about" element={<AboutPage />} />
          <Route path="/services" element={<ServicesPage />} />
        </Routes>
      </main>
    </div>
  );
}
```

## 💡 **핵심 개념 복습**

### **1. Route의 역할**

- `path` prop: URL 경로를 정의
- `element` prop: 해당 경로에서 렌더링할 컴포넌트 지정
- React Router는 현재 URL과 일치하는 Route를 찾아 해당 컴포넌트를 렌더링

### **2. Link의 역할**

- `to` prop: 이동할 경로 지정
- `<a>` 태그와 달리 페이지 전체를 새로고침하지 않음
- SPA(Single Page Application) 방식으로 부드러운 페이지 전환 제공

### **3. Import/Export 패턴**

- Named Export 사용: `export function ServicesPage() {}`
- Named Import 사용: `import { ServicesPage } from './pages/ServicesPage'`
- 이는 Codeit 프로젝트의 코딩 컨벤션을 따른 것

## ✅ **동작 확인 방법**

1. **네비게이션 확인**: 헤더에 Home, About, Services 3개의 링크가 나타나는지 확인
2. **URL 변경 확인**: Services 링크 클릭 시 브라우저 주소창이 `/services`로 변경되는지 확인
3. **페이지 렌더링 확인**: Services 페이지의 내용이 화면에 올바르게 표시되는지 확인
4. **뒤로가기 확인**: 브라우저의 뒤로가기 버튼이 정상적으로 작동하는지 확인
