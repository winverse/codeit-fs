# 해설: 03. Dynamic Routes 응용

## 🎯 챌린지 목표

`useParams` 훅을 사용하여, URL의 동적 파라미터에 따라 다른 상품의 상세 정보를 보여주는 페이지를 구현합니다. 강의에서 배운 개념을 새로운 데이터 구조와 경로에 응용하는 방법을 연습합니다.

## 📝 단계별 해설

### **1단계: `App.jsx`에 동적 라우트 설정**

먼저 `App.jsx` 파일에서 상품 상세 페이지로 연결될 동적 라우트를 설정합니다.

```jsx
// App.jsx (수정 전)
// TODO: ProductDetailPage를 import 하세요
// ...
{/* TODO: /products/:productId 동적 경로를 설정하세요 */}
```

강의에서 `/posts/:postId`를 설정했던 것과 동일한 원리입니다. `ProductDetailPage`를 import하고, `path`에 `:productId`라는 동적 세그먼트를 포함한 경로를 설정합니다.

```jsx
// App.jsx (수정 후)
import { ProductDetailPage } from './pages/ProductDetailPage';

// ...
<Route path="/products/:productId" element={<ProductDetailPage />} />
```

### **2단계: `ProductDetailPage.jsx`에서 데이터 조회 및 렌더링**

상세 페이지 컴포넌트에서 URL 파라미터를 이용해 실제 데이터를 찾아 화면에 보여줍니다.

#### **TODO 1: `useParams`로 `productId` 가져오기**

```jsx
// ProductDetailPage.jsx (수정 전)
// TODO 1: useParams 훅을 사용하여 URL로부터 productId를 가져오세요.
```

`useParams` 훅을 호출하여 `App.jsx`에서 설정한 동적 세그먼트 `:productId` 값을 객체 형태로 가져옵니다.

```jsx
// ProductDetailPage.jsx (수정 후)
const { productId } = useParams();
```

#### **TODO 2: `productId`로 상품 찾기**

```jsx
// ProductDetailPage.jsx (수정 전)
// TODO 2: products 배열에서, 위에서 얻은 productId와 일치하는 상품을 찾으세요.
```

`products` 데이터 배열의 `find` 메서드를 사용하여, URL을 통해 얻은 `productId`와 `id`가 일치하는 상품 객체를 찾습니다.

```jsx
// ProductDetailPage.jsx (수정 후)
const product = products.find(p => p.id === productId);
```

#### **TODO 3: 조건부 렌더링**

```jsx
// ProductDetailPage.jsx (수정 전)
// TODO 3: 만약 product가 존재하지 않는다면, 아래 "상품을 찾을 수 없습니다" 메시지를 보여주세요.
```

`find` 메서드는 일치하는 항목이 없으면 `undefined`를 반환합니다. 이 특성을 이용하여, `product`가 존재하지 않을 경우 (falsy일 경우) 에러 메시지를 렌더링하도록 처리합니다.

```jsx
// ProductDetailPage.jsx (수정 후)
if (!product) {
  return <div className={styles.error}>상품을 찾을 수 없습니다.</div>;
}
```

## 🎉 최종 완성 코드

```jsx
// src/pages/ProductDetailPage.jsx (최종)
import { useParams, Link } from 'react-router-dom';
import { products } from '../../data/products';
import styles from './ProductDetailPage.module.css';

export function ProductDetailPage() {
  const { productId } = useParams();
  const product = products.find(p => p.id === productId);

  if (!product) {
    return <div className={styles.error}>상품을 찾을 수 없습니다.</div>;
  }

  return (
    <div className={styles.page}>
      <Link to="/products" className={styles.backLink}>
        ← 상품 목록으로
      </Link>
      <div className={styles.productCard}>
        <h1 className={styles.productName}>{product.name}</h1>
        <p className={styles.productPrice}>
          가격: {product.price.toLocaleString()}원
        </p>
        <p className={styles.productDescription}>{product.description}</p>
      </div>
    </div>
  );
}
```

이번 챌린지를 통해 강의에서 배운 동적 라우팅 개념을, 실제 쇼핑몰의 상품 상세 페이지와 유사한 기능에 직접 응용하는 방법을 연습했습니다.
