# 해설: 04. Not Found와 Redirect 응용

## 🎯 챌린지 목표

`Navigate` 컴포넌트와 `path="*"`를 사용하여 리다이렉트와 Not Found 페이지를 구현하는 방법을 응용해봅니다.

## 📝 단계별 해설

`App.jsx` 파일의 `TODO` 주석을 따라 두 가지 핵심 기능을 구현합니다.

### **1단계: `/old-home` 리다이렉트 구현**

첫 번째 `TODO`는 `/old-home` 경로를 `/`로 리다이렉트하는 것입니다. `04`챕터 강의에서 배운 `Navigate` 컴포넌트를 사용합니다.

```jsx
// App.jsx (수정 전)

{/* TODO: /old-home 경로로 접속하면 / 로 리다이렉트 시키세요. */}
{/* HINT: Navigate 컴포넌트를 사용하고, replace prop을 true로 설정하세요. */}
```

`<Route>`의 `element` prop에 `<Navigate>` 컴포넌트를 전달합니다. `to` prop에는 목표 경로인 `/`를, `replace` prop에는 `true`를 전달하여 브라우저 히스토리에 `/old-home`이 남지 않도록 합니다.

```jsx
// App.jsx (수정 후)

<Route 
  path="/old-home" 
  element={<Navigate to="/" replace />}
/>
```

### **2단계: Not Found 페이지 구현**

두 번째 `TODO`는 정의되지 않은 모든 경로에 대해 `NotFoundPage`를 보여주는 것입니다. `path="*"`를 사용하는 "Catch-all" 라우트를 `Routes` 컴포넌트의 가장 마지막에 추가합니다.

```jsx
// App.jsx (수정 전)

{/* TODO: 위의 어떤 경로와도 일치하지 않으면 NotFoundPage를 보여주세요. */}
{/* HINT: path="*" 를 사용하면 모든 경로와 일치시킬 수 있습니다. */}
```

이 라우트는 다른 모든 경로와 매칭을 시도한 후, 일치하는 것이 없을 때 최후의 보루처럼 작동합니다.

```jsx
// App.jsx (수정 후)

<Route path="*" element={<NotFoundPage />} />
```

## 🎉 최종 완성 코드

```jsx
// src/App.jsx (최종)

import { Routes, Route, Link, Navigate } from 'react-router';
import { HomePage } from './pages/Home';
import { ProfilePage } from './pages/Profile';
import { NotFoundPage } from './pages/NotFound';

export function App() {
  return (
    <div className="app">
      <header>
        <nav>
          <Link to="/">Home</Link>
          <Link to="/profile">Profile</Link>
        </nav>
      </header>
      <main>
        <Routes>
          <Route path="/" element={<HomePage />} />
          <Route path="/profile" element={<ProfilePage />} />

          {/* 1. /old-home 리다이렉트 */}
          <Route 
            path="/old-home" 
            element={<Navigate to="/" replace />}
          />

          {/* 2. Not Found 페이지 */}
          <Route path="*" element={<NotFoundPage />} />
        </Routes>
      </main>
    </div>
  );
}
```

## ✅ 확인하기

1.  **리다이렉트 확인**: 브라우저에서 `/old-home`으로 접속하면 URL이 `/`로 바뀌면서 홈페이지가 나타납니다.
2.  **Not Found 확인**: 브라우저에서 `/asdf` 와 같이 존재하지 않는 경로로 접속하면 "404 - 페이지를 찾을 수 없습니다!" 메시지가 나타납니다.

이번 챌린지를 통해 강의에서 배운 개념을 새로운 요구사항에 맞게 응용하는 방법을 연습했습니다.
