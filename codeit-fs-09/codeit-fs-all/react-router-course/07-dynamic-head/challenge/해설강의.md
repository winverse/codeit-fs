# 해설: 07. Dynamic Head 응용

## 🎯 챌린지 목표

`react-helmet-async` 라이브러리를 사용하여, 여러 페이지에 각기 다른 종류의 동적 헤드 정보를 적용하는 방법을 응용해봅니다.

## 📝 단계별 해설

### **1단계: `HelmetProvider` 설정**

가장 먼저 `main.jsx` 파일에서 `HelmetProvider`를 설정하여 앱 전체에서 Helmet 기능을 활성화합니다. 이는 강의 내용과 동일합니다.

```jsx
// src/main.jsx (수정 후)
import { HelmetProvider } from 'react-helmet-async';

// ...
root.render(
  <StrictMode>
    <HelmetProvider>
      <BrowserRouter>
        <App />
      </BrowserRouter>
    </HelmetProvider>
  </StrictMode>
);
```

### **2단계: `PortfolioPage`에 헤드 정보 추가 (심화)**

`PortfolioPage.jsx`에서는 제목, 설명과 더불어 소셜 미디어 공유를 위한 오픈그래프(Open Graph) 태그까지 추가합니다.

```jsx
// src/pages/Portfolio/PortfolioPage.jsx (수정 후)
import { Link } from 'react-router-dom';
import { Helmet } from 'react-helmet-async';

export function PortfolioPage() {
  return (
    <div className="page-content">
      <Helmet>
        <title>포트폴리오 - 내 프로젝트들</title>
        <meta
          name="description"
          content="저의 프로젝트들을 소개하는 포트폴리오 페이지입니다."
        />
        <meta property="og:title" content="Codeit | 제 포트폴리오를 소개합니다." />
        <meta
          property="og:description"
          content="React와 React Router로 만든 멋진 프로젝트들을 구경해보세요."
        />
        <meta property="og:image" content="/og-image.png" />
      </Helmet>

      {/* ... 페이지 내용 ... */}
    </div>
  );
}
```

### **3단계: `ContactPage`에 헤드 정보 추가 (기본)**

`ContactPage.jsx`에서는 기본적인 `<title>`과 `<meta name="description">`만 추가하여 배운 내용을 복습합니다.

```jsx
// src/pages/Contact/ContactPage.jsx (수정 후)
import { Link } from 'react-router-dom';
import { Helmet } from 'react-helmet-async';

export function ContactPage() {
  return (
    <div className="page-content">
      <Helmet>
        <title>문의하기 - React Router 학습</title>
        <meta
          name="description"
          content="궁금한 점이 있다면 언제든지 문의해주세요."
        />
      </Helmet>

      {/* ... 페이지 내용 ... */}
    </div>
  );
}
```

## ✅ 확인하기

1.  **포트폴리오 페이지**: `/portfolio`로 접속하여 개발자 도구의 `<head>` 섹션을 확인하면, `title`, `description`, `og:title`, `og:description`, `og:image` 태그가 모두 올바르게 추가된 것을 볼 수 있습니다.
2.  **문의하기 페이지**: `/contact`로 접속하면 `title`과 `description`만 간결하게 추가된 것을 확인할 수 있습니다.

이번 챌린지를 통해 기본 헤드 정보 설정부터 오픈그래프 태그를 활용한 심화 SEO 최적화까지, 다양한 상황에 맞게 동적 헤드를 관리하는 방법을 연습했습니다.
