## 🎉 **최종 완성 코드**

### **App.jsx**

```jsx
import { Routes, Route } from 'react-router';
import { Layout } from './components/Layout';
import { HomePage } from './pages/Home';
import { ProductsPage } from './pages/ProductsPage';
import { ProductsHomePage } from './pages/ProductsHomePage';
import { CategoryPage } from './pages/CategoryPage';

export function App() {
  return (
    <Routes>
      <Route path="/" element={<Layout />}>
        <Route index={true} element={<HomePage />} />
        <Route path="products" element={<ProductsPage />}>
          <Route index={true} element={<ProductsHomePage />} />
          <Route path="category" element={<CategoryPage />} />
        </Route>
      </Route>
    </Routes>
  );
}
```

### **ProductsPage.jsx**

```jsx
import { Outlet, Link } from 'react-router';
import styles from './ProductsPage.module.css';

export function ProductsPage() {
  return (
    <div className={styles.page}>
      <h2>Products</h2>
      <nav className={styles.nav}>
        <Link to="/products">Home</Link>
        <Link to="/products/category">Category</Link>
      </nav>
      <hr />
      <div className={styles.content}>
        <Outlet />
      </div>
    </div>
  );
}
```

## 💡 **핵심 개념 복습**

### **1. 중첩 라우팅(Nested Routes)**

- 부모 Route 안에 자식 Route들을 중첩시키는 구조
- URL 경로가 계층적으로 구성됨: `/products` → `/products/category`
- 부모 컴포넌트의 레이아웃을 유지하면서 자식 컴포넌트만 변경

### **2. Outlet 컴포넌트**

- 자식 Route에 해당하는 컴포넌트가 렌더링될 위치를 지정
- 부모 컴포넌트에서 `<Outlet />`을 사용하여 자식 컴포넌트를 렌더링
- 공통 레이아웃을 유지하면서 특정 영역만 변경할 때 유용

### **3. Index Route**

- `index={true}` prop을 가진 Route
- 부모 경로에 정확히 일치할 때 렌더링되는 기본 자식 Route
- `/products` 접속 시 `ProductsHomePage`가 렌더링됨

### **4. 경로 구조**

```
/ (Layout)
├── / (HomePage) - index route
└── /products (ProductsPage)
    ├── /products (ProductsHomePage) - index route
    └── /products/category (CategoryPage)
```

## ✅ **동작 확인 방법**

1. **기본 경로 확인**: `/products` 접속 시 ProductsPage 레이아웃 안에 ProductsHomePage가 표시되는지 확인
2. **자식 경로 확인**: `/products/category` 접속 시 같은 ProductsPage 레이아웃 안에 CategoryPage가 표시되는지 확인
3. **네비게이션 확인**: ProductsPage 내부의 Home, Category 링크가 올바르게 작동하는지 확인
4. **레이아웃 유지 확인**: 페이지 전환 시 ProductsPage의 헤더와 네비게이션이 유지되고 content 영역만 변경되는지 확인
