# Redux Toolkit 강의 코스 목차

> **대상 기술**: Redux Toolkit v2.90 (최신 버전)  
> **대상 수준**: React 기초를 이해하고 있는 개발자  
> **학습 목표**: 현대적인 Redux 상태 관리를 Redux Toolkit으로 효율적으로 구현하기

---

## 📋 전체 강의 구성

### **PART 1: Redux Toolkit 기초**

#### **01-redux-toolkit-introduction**

- **학습 목표**: Redux의 문제점과 Redux Toolkit의 필요성 이해
- **주요 개념**:
  - 전통적인 Redux의 보일러플레이트 문제
  - Redux Toolkit이 해결하는 핵심 문제들
  - 설치 및 기본 설정
- **실습**: 전통적인 Redux vs Redux Toolkit 비교 체험

#### **02-configureStore-basics**

- **학습 목표**: configureStore로 간단한 Redux 스토어 설정하기
- **주요 개념**:
  - `configureStore` 함수의 기본 사용법
  - 자동 미들웨어 설정 (Redux DevTools, thunk 등)
  - TypeScript 타입 정의 (`RootState`, `AppDispatch`)
- **실습**: 기본 카운터 앱 스토어 설정

#### **03-createSlice-fundamentals**

- **학습 목표**: createSlice로 reducer와 action 동시에 생성하기
- **주요 개념**:
  - `createSlice` 함수의 구조와 사용법
  - Immer를 활용한 불변성 관리
  - 자동 action creator 생성
- **실습**: 카운터 slice 구현 (increment, decrement, incrementByAmount)

#### **04-react-redux-integration**

- **학습 목표**: React 컴포넌트에서 Redux Toolkit 사용하기
- **주요 개념**:
  - Provider 컴포넌트로 스토어 제공
  - useSelector와 useDispatch 훅 사용
  - 타입 안전한 훅 생성 (useAppSelector, useAppDispatch)
- **실습**: React 컴포넌트에서 카운터 상태 관리

---

### **PART 2: 상태 관리 심화**

#### **05-multiple-slices**

- **학습 목표**: 여러 slice를 조합한 복합 상태 관리
- **주요 개념**:
  - 여러 slice를 하나의 스토어에 통합
  - slice 간 상태 의존성 관리
  - 모듈화된 상태 구조 설계
- **실습**: 사용자 정보 + 할 일 목록 앱 구현

#### **06-extraReducers-cross-slice**

- **학습 목표**: slice 간 action에 반응하는 cross-slice logic 구현
- **주요 개념**:
  - `extraReducers`를 이용한 외부 action 처리
  - builder callback 패턴 사용법
  - slice 간 연관 관계 설정
- **실습**: 사용자 로그인 시 관련 데이터 초기화

---

### **PART 3: 비동기 작업 처리**

#### **07-createAsyncThunk-basics**

- **학습 목표**: 비동기 작업을 위한 createAsyncThunk 사용법
- **주요 개념**:
  - `createAsyncThunk`의 기본 구조
  - pending, fulfilled, rejected 상태 관리
  - 비동기 작업의 생명주기 이해
- **실습**: API에서 사용자 목록 가져오기

#### **08-async-thunk-advanced**

- **학습 목표**: 고급 비동기 패턴과 에러 처리
- **주요 개념**:
  - thunk 조건부 실행 (condition)
  - 직렬화 가능한 에러 처리
  - loading 상태 UI 패턴
  - 재시도 로직 구현
- **실습**: 로딩, 에러, 성공 상태가 있는 데이터 페칭

#### **09-thunk-api-utilities**

- **학습 목표**: thunk에서 제공하는 다양한 API 활용
- **주요 개념**:
  - `getState`로 현재 상태 접근
  - `dispatch`로 다른 action 호출
  - `rejectWithValue`로 에러 커스터마이징
  - `signal`을 이용한 중단 처리
- **실습**: 사용자 프로필 업데이트 (현재 상태 기반 업데이트)

---

## 📚 각 챕터 구성

각 챕터는 다음과 같이 구성됩니다:

- **`starter/`**: 강의 시작 코드 (기본 Vite React 프로젝트)
- **`solution/`**: 강의 완료 코드 (시연 결과물)
- **`challenge/`**: 학생 실습 과제 (해당 챕터 핵심 개념만 연습)
- **`README.md`**: 학습 목표, 개념 설명, 강의 스크립트, 과제 안내
