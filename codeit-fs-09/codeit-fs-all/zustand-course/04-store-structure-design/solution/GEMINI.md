# 스토어 구조 설계 - Solution

이 프로젝트는 Zustand를 사용한 **올바른 스토어 구조 설계**의 예시입니다.

## 해결된 문제점들

### 1. 정규화된 상태 구조
- 관련된 데이터를 논리적으로 그룹화
- 계층적 구조로 관심사 분리
- 스토어 분할을 통한 책임 분산

### 2. 계산된 값 (Computed Values)
- 셀렉터를 통한 파생 상태 관리
- 컴포넌트의 계산 로직 부담 감소
- 성능 최적화된 데이터 접근

### 3. 액션과 상태의 분리
- 비즈니스 로직의 캡슐화
- 재사용 가능한 액션 함수
- 명확한 데이터 흐름

### 4. 타입 안정성 및 개발자 경험
- 명확한 인터페이스 정의
- 예측 가능한 상태 변화
- 디버깅 친화적 구조

## 주요 개선사항

- **모듈화**: 기능별로 분리된 스토어
- **선택자**: 최적화된 데이터 접근
- **액션 캡슐화**: 비즈니스 로직 분리
- **타입 안정성**: 명확한 데이터 구조

## 기술 스택

- React 18
- Zustand (상태 관리)
- Vite (빌드 도구)
- CSS Modules (스타일링)

## 프로젝트 구조

```
src/
├── stores/          # 상태 관리
│   ├── productStore.js
│   ├── cartStore.js
│   ├── uiStore.js
│   └── index.js
├── components/      # UI 컴포넌트
├── hooks/          # 커스텀 훅
├── selectors/      # 계산된 값
├── data/          # 샘플 데이터
└── utils/         # 유틸리티 함수
```

## 실행 방법

```bash
npm install
npm run dev
```
