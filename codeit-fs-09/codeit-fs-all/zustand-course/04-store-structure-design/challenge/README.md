# 챌린지: 재고 관리 시스템 - Challenge

재고 관리 시스템을 구현하면서 Zustand의 올바른 스토어 구조 설계를 연습하는 프로젝트입니다.

## 기술 스택

- React 18
- Zustand (상태 관리)
- Vite (빌드 도구) 
- CSS Modules (스타일링)

## 주요 기능

- 📦 상품별 재고 관리 (입고/출고)
- 🛒 주문 시스템 (재고 연동)
- 📊 재고 현황 대시보드
- 🔍 상품 필터링 및 정렬
- ⚠️ 재고 알림 시스템

## 학습 목표

1. **스토어 분리**: 책임에 따른 스토어 설계
2. **셀렉터 활용**: 계산된 값의 효율적 관리  
3. **커스텀 훅**: 비즈니스 로직 캡슐화
4. **스토어 통신**: 다중 스토어 간 데이터 흐름
5. **성능 최적화**: 필요한 상태만 구독
