# 챌린지 해설: 고급 네비게이션 실습

이번 챌린지의 목표는 인증 상태에 따라 UI가 동적으로 변경되고, 특정 페이지를 보호하는 방법을 익히는 것입니다. `useAuth`라는 커스텀 훅을 중심으로 `Context`와 라우팅을 결합하는 강력한 패턴을 실습합니다.

## 1. `AuthProvider.js` 완성하기

가장 먼저, 애플리케이션의 인증 상태를 관리할 `AuthProvider` 로직을 완성합니다. `useState`를 사용하여 `user` 상태를 만들고, `login`과 `logout` 함수가 이 상태를 변경하도록 구현합니다. `isAuthenticated`는 `user` 상태가 `null`인지 아닌지에 따라 동적으로 계산되는 값입니다.

```javascript
// src/hooks/useAuth.js
export function AuthProvider({ children }) {
  const [user, setUser] = useState(null);

  const login = () => {
    // 간단한 사용자 객체로 로그인 상태를 시뮬레이션합니다.
    setUser({ name: 'Student' });
  };

  const logout = () => {
    // 사용자 객체를 null로 만들어 로그아웃 상태로 변경합니다.
    setUser(null);
  };

  // user 객체가 존재하면 true, 그렇지 않으면 false가 됩니다.
  const isAuthenticated = !!user;

  return (
    <AuthContext.Provider value={{ user, isAuthenticated, login, logout }}>
      {children}
    </AuthContext.Provider>
  );
}
```

```js
// TODO: Provider를 보고 기본 값으로 채우세요
export const AuthContext = createContext({
  user: null,
  isAuthenticated: false,
  login: () => {},
  logout: () => {},
});

export function useAuth() {
  const context = useContext(AuthContext);
  if (!context) {
    throw new Error('useAuth must be used within an AuthProvider');
  }
  return context;
}
```

## 2. `__root.jsx` 동적 네비게이션 구현

`useAuth` 훅을 사용하여 현재 인증 상태(`isAuthenticated`)를 가져오고, 이 값에 따라 다른 UI를 보여주는 조건부 렌더링을 구현합니다.

- `isAuthenticated`가 `true`이면 "Profile" 링크와 "Logout" 버튼을 보여줍니다.
- `isAuthenticated`가 `false`이면 "Login" 링크만 보여줍니다.

```jsx
// src/routes/__root.jsx
import { createRootRoute, Outlet, Link } from '@tanstack/react-router';
import { useAuth } from '../hooks/useAuth';

export const Route = createRootRoute({
  component: RootComponent,
});

function RootComponent() {
  const { isAuthenticated, logout } = useAuth();

  return (
    <div className="app-layout">
      <header className="header">
        <div className="header-content">
          <h1>Auth Challenge</h1>
          <div className="user-actions">
            {isAuthenticated ? (
              <>
                <Link to="/profile" className="btn btn-sm">
                  Profile
                </Link>
                <button onClick={logout} className="btn btn-sm">
                  Logout
                </button>
              </>
            ) : (
              <Link to="/login" className="btn btn-sm">
                Login
              </Link>
            )}
          </div>
        </div>
      </header>
      {/* ... nav, main ... */}
      {/* ... 로그인 상태일 때만 ... */}
      {isAuthenticated && (
        <li>
          <Link to="/profile">Profile</Link>
        </li>
      )}
      
    </div>
  );
}
```

## 3. `profile.jsx` 보호된 라우트 생성

로그인한 사용자만 접근할 수 있는 페이지를 만듭니다. `src/routes/profile.jsx` 파일을 새로 생성하고, 페이지 컴포넌트의 최상단에서 `useAuth` 훅으로 인증 상태를 확인합니다.

만약 `isAuthenticated`가 `false`이면, TanStack Router의 `<Navigate />` 컴포넌트를 사용하여 `/login` 경로로 즉시 리디렉션합니다. 이것이 바로 **네비게이션 가드(Navigation Guard)** 의 핵심 원리입니다.

```jsx
// src/routes/profile.jsx
import { createFileRoute, Navigate } from '@tanstack/react-router';
import { useAuth } from '../hooks/useAuth';

export const Route = createFileRoute('/profile')({
  component: ProfilePage,
});

function ProfilePage() {
  const { isAuthenticated, user } = useAuth();

  // 네비게이션 가드
  if (!isAuthenticated) {
    return <Navigate to="/login" />;
  }

  return (
    <div className="page-content">
      <h1>Welcome, {user.name}!</h1>
      <p>This is your protected profile page.</p>
    </div>
  );
}
```

## 4. `login.jsx` 프로그래매틱 네비게이션 구현

로그인 성공 후, 사용자를 특정 페이지로 자동으로 이동시키는 기능을 구현합니다. `useNavigate` 훅을 사용하여 `navigate` 함수를 가져옵니다.

"Login" 버튼의 `onClick` 핸들러에서 `login()` 함수를 호출한 직후, `navigate({ to: '/profile' })`를 호출하여 사용자를 프로필 페이지로 이동시킵니다. 이것을 **프로그래매틱 네비게이션(Programmatic Navigation)** 이라고 합니다.

```jsx
// src/routes/login.jsx
import { createFileRoute, useNavigate } from '@tanstack/react-router';
import { useAuth } from '../hooks/useAuth';

export const Route = createFileRoute('/login')({
  component: LoginPage,
});

function LoginPage() {
  const { login } = useAuth();
  const navigate = useNavigate();

  const handleLogin = () => {
    login();
    navigate({ to: '/profile' });
  };

  return (
    <div className="login-container">
      <h1 className="login-title">Login</h1>
      <p style={{ textAlign: 'center', marginBottom: '2rem' }}>
        Click the button below to log in.
      </p>
      <button onClick={handleLogin} className="btn btn-full-width">
        Login as Student
      </button>
    </div>
  );
}
```

## 핵심 정리

- **동적 UI**: `useAuth`와 같은 커스텀 훅의 상태에 따라 UI(네비게이션 메뉴 등)를 다르게 렌더링할 수 있습니다.
- **네비게이션 가드**: 컴포넌트 초기에 권한을 확인하고, 조건이 맞지 않으면 `<Navigate />` 컴포넌트로 다른 페이지로 튕겨낼 수 있습니다.
- **프로그래매틱 네비게이션**: `useNavigate` 훅을 사용하면, 특정 로직(예: 폼 제출 성공)이 완료된 후 코드로 사용자를 다른 페이지로 이동시킬 수 있습니다.
