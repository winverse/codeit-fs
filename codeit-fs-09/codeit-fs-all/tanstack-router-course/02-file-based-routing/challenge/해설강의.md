### 3단계: 네비게이션 완성

**파일 위치**: `src/routes/__root.tsx`

```tsx
import { createRootRoute, Link, Outlet } from '@tanstack/react-router'

export const Route = createRootRoute({
  component: () => (
    <div>
      <nav>
        <ul>
          <li><Link to="/">Home</Link></li>
          <li><Link to="/about">About</Link></li>
          <li><Link to="/services">Services</Link></li>
          <li><Link to="/company">Company</Link></li>
        </ul>
      </nav>
      <main>
        <Outlet />
      </main>
    </div>
  ),
})
```

**핵심 학습 포인트:**
- 논리적인 메뉴 순서 구성
- 메인 섹션만 네비게이션에 표시 (상세 페이지는 내부 링크로)
- 일관된 네비게이션 패턴 유지

## 🚀 고급 구현 아이디어

### 1. 동적 메뉴 시스템

```tsx
const menuItems = [
  { to: '/', label: 'Home' },
  { to: '/about', label: 'About' },
  { to: '/services', label: 'Services' },
  { to: '/company', label: 'Company' },
]

// 네비게이션에서 사용
{menuItems.map(item => (
  <li key={item.to}>
    <Link to={item.to}>{item.label}</Link>
  </li>
))}
```

### 2. 활성 링크 스타일링

### 3. 브레드크럼 내비게이션

```tsx
import { useRouter } from '@tanstack/react-router'

function Breadcrumb() {
  const router = useRouter()
  const pathname = router.state.location.pathname
  
  const breadcrumbs = pathname
    .split('/')
    .filter(Boolean)
    .map((segment, index, array) => ({
      label: segment.charAt(0).toUpperCase() + segment.slice(1),
      path: '/' + array.slice(0, index + 1).join('/')
    }))
  
  return (
    <nav style={{ marginBottom: '1rem' }}>
      <Link to="/">Home</Link>
      {breadcrumbs.map((crumb, index) => (
        <span key={index}>
          {' > '}
          <Link to={crumb.path}>{crumb.label}</Link>
        </span>
      ))}
    </nav>
  )
}
```

## 💡 일반적인 실수와 해결법

### 실수 1: 폴더 구조와 URL 불일치
```
❌ 잘못된 구조:
src/routes/services.tsx        → /services (파일)
src/routes/services/web.tsx    → 작동하지 않음

✅ 올바른 구조:
src/routes/services/index.tsx  → /services
src/routes/services/web.tsx    → /services/web
```

### 실수 2: 링크 경로 오타
```tsx
// ❌ 잘못된 예
<Link to="/service">Services</Link>  // 경로 오타

// ✅ 올바른 예
<Link to="/services">Services</Link>
```

### 실수 3: 일관성 없는 스타일링
```tsx
// ❌ 각 페이지마다 다른 스타일
<div style={{ padding: '1rem' }}>        // 페이지 A
<div style={{ padding: '2rem' }}>        // 페이지 B

// ✅ 일관된 클래스 사용
<div className="page-content">           // 모든 페이지
```

## 🔍 해결 과정에서 배운 것들

### 파일 기반 라우팅 마스터
1. **폴더 구조 = URL 구조**: 직관적이고 예측 가능
2. **index.tsx의 역할**: 폴더의 기본 페이지
3. **중첩 라우팅**: 자연스러운 계층 구조

### React 컴포넌트 설계
1. **재사용 가능한 구조**: 일관된 레이아웃과 스타일
2. **의미있는 콘텐츠**: 실제 프로젝트에 활용 가능한 수준
3. **사용자 경험**: 뒤로가기 링크, 논리적 내비게이션

### 개발 효율성
1. **자동 라우트 생성**: 파일 생성만으로 즉시 접근 가능
2. **타입 안전성**: 존재하지 않는 경로 링크 시 TypeScript 에러
3. **핫 리로딩**: 변경사항 즉시 반영
