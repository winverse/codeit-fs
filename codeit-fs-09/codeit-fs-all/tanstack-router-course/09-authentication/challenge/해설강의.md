# 챌린지 해설: 보호된 라우트와 인증 가드 구현

이번 챌린지의 목표는 `beforeLoad` 훅을 사용하여 특정 라우트를 보호하고, 인증되지 않은 사용자를 로그인 페이지로 안내하는 것입니다.

## 1. 라우터에 인증 컨텍스트 제공

`beforeLoad` 가드에서 인증 상태에 접근하려면, 라우터가 인증 컨텍스트를 알고 있어야 합니다. `src/main.jsx`에서 `createRouter`를 설정할 때 `context` 옵션을 통해 `auth` 객체를 주입합니다. 이 `auth` 객체는 `useAuth()` 훅에서 가져온 값입니다.

```jsx
// src/main.jsx
// ...
import { AuthProvider, useAuth } from './hooks/useAuth';

// ...
const router = createRouter({
  routeTree,
  context: {
    auth: undefined, // 초기값 설정
  },
});

// InnerApp 컴포넌트를 만들어 useAuth 훅을 사용합니다.
function InnerApp() {
  const auth = useAuth();
  // 라우터 프로바이더에 context를 전달합니다.
  return <RouterProvider router={router} context={{ auth }} />;
}

ReactDOM.createRoot(document.getElementById('root')).render(
  <React.StrictMode>
    <AuthProvider>
      <InnerApp />
    </AuthProvider>
  </React.StrictMode>,
);
```

## 2. `beforeLoad` 인증 가드 구현

`src/routes/dashboard.jsx` 파일에서 `beforeLoad` 훅을 구현합니다. 이 훅은 `context` 객체를 인자로 받으므로, 우리는 `context.auth.isAuthenticated`를 통해 현재 로그인 상태를 확인할 수 있습니다.

만약 `isAuthenticated`가 `false`이면, TanStack Router의 `redirect` 유틸리티를 `throw`하여 사용자를 `/login` 페이지로 즉시 리디렉션시킵니다.

```jsx
// src/routes/dashboard.jsx
import { createFileRoute, redirect } from '@tanstack/react-router';

export const Route = createFileRoute('/dashboard')({
  // beforeLoad 가드 구현
  beforeLoad: ({ context }) => {
    if (!context.auth.isAuthenticated) {
      // 인증되지 않았으면 로그인 페이지로 리디렉션
      throw redirect({
        to: '/login',
      });
    }
  },
  component: DashboardPage,
});

function DashboardPage() {
  return (
    <div className="page-content">
      <h1>Dashboard</h1>
      <p>Welcome! You can only see this page if you are logged in.</p>
    </div>
  );
}
```

## 3. 로그인 페이지 기능 완성

`src/routes/login.jsx` 파일에서, 사용자가 "Login" 버튼을 클릭했을 때의 동작을 구현합니다. `useAuth` 훅으로 `login` 함수를, `useNavigate` 훅으로 `navigate` 함수를 가져옵니다.

`handleLogin` 함수 내에서 `login()`을 호출하여 인증 상태를 변경한 후, `navigate()`를 호출하여 사용자를 원래 가려던 대시보드 페이지(`/dashboard`)로 이동시킵니다.

```jsx
// src/routes/login.jsx
import { createFileRoute, useNavigate } from '@tanstack/react-router';
import { useAuth } from '../../hooks/useAuth';

export const Route = createFileRoute('/login')({
  component: LoginPage,
});

function LoginPage() {
  const { login } = useAuth();
  const navigate = useNavigate();

  const handleLogin = () => {
    login();
    navigate({ to: '/dashboard' });
  };

  return (
    <div className="form-container">
      <h1 className="form-title">Login Required</h1>
      <p style={{ textAlign: 'center', marginBottom: '2rem' }}>
        You need to log in to access this page.
      </p>
      <button onClick={handleLogin} className="btn btn-full-width">
        Login
      </button>
    </div>
  );
}
```

## 핵심 정리

-   **`beforeLoad`**: 라우트의 `loader`나 `component`가 실행되기 전에 실행되므로, 접근 권한을 확인하는 데 최적의 장소입니다.
-   **`redirect`**: `beforeLoad` 내에서 `throw`와 함께 사용되어, 현재의 네비게이션을 중단하고 다른 경로로 즉시 전환합니다.
-   **Router `context`**: 라우터 전반에 걸쳐 필요한 전역 상태(인증, 테마 등)를 `beforeLoad`와 같은 훅에 안전하게 전달하는 통로입니다.

축하합니다! 이제 TanStack Router의 강력한 `beforeLoad` 가드를 사용하여 안전한 애플리케이션을 만들 수 있게 되었습니다.
