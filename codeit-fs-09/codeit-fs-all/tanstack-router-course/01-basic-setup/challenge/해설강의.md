# 챌린지 해설: 기본 TanStack Router 설정

이번 챌린지의 목표는 TanStack Router의 핵심인 파일 기반 라우팅을 이해하고, 새로운 페이지를 추가하며, 네비게이션을 업데이트하는 것입니다.

## 1. `contact.jsx` 파일 생성

가장 먼저, `src/routes/` 폴더에 `contact.jsx`라는 새 파일을 만듭니다. TanStack Router는 이 파일의 경로를 자동으로 인식하여 `/contact`라는 URL을 생성합니다.

`createFileRoute`를 사용하여 라우트를 정의하고, `component` 옵션에 페이지의 JSX를 작성합니다. 중요한 점은 인라인 스타일 대신 `src/index.css`에 미리 정의된 `className`을 사용하여 스타일을 적용하는 것입니다. 이는 코드의 일관성과 유지보수성을 높여줍니다.

```jsx
// src/routes/contact.jsx
import { createFileRoute } from '@tanstack/react-router';

export const Route = createFileRoute('/contact')({
  component: () => (
    <div>
      <h1>Contact Us</h1>
      <p>Contact Page 입니다</p>
    </div>
  ),
});
```

## 2. `__root.jsx` 네비게이션 수정

다음으로, 모든 페이지의 공통 레이아웃 역할을 하는 `src/routes/__root.jsx` 파일을 수정해야 합니다. 네비게이션(`<ul>` 태그) 안에 새로운 `<li>` 항목을 추가하여 방금 만든 Contact 페이지로 이동하는 링크를 만듭니다.

`Link` 컴포넌트의 `to` prop에 `/contact`를 지정합니다. 또한, `activeProps`를 사용하여 현재 페이지일 때 적용될 스타일을 지정하는 것을 잊지 마세요. 이는 사용자 경험을 향상시키는 중요한 디테일입니다.

```jsx
// src/routes/__root.jsx
import { createRootRoute, Link, Outlet } from '@tanstack/react-router';

export const Route = createRootRoute({
  component: () => (
    <>
      <nav>
        <ul>
          <li>
            <Link to="/" activeProps={{ className: 'active' }}>
              Home
            </Link>
          </li>
          <li>
            <Link to="/about" activeProps={{ className: 'active' }}>
              About
            </Link>
          </li>
          <li>
            <Link to="/contact" activeProps={{ className: 'active' }}>
              Contact
            </Link>
          </li>
        </ul>
      </nav>
      <main>
        <Outlet />
      </main>
    </>
  ),
});
```

## 핵심 정리

- **파일 기반 라우팅**: `src/routes` 폴더에 파일을 만드는 것만으로도 새로운 페이지가 생성됩니다.
- **스타일 일관성**: 전역 CSS(`index.css`)와 `className`을 사용하여 모든 페이지의 디자인을 일관되게 유지할 수 있습니다.
- **네비게이션**: `Link` 컴포넌트와 `to` prop을 사용하여 페이지 간 이동을 구현합니다.
- **Active 스타일**: `activeProps`를 사용하면 현재 활성화된 링크에 쉽게 스타일을 적용할 수 있습니다.

이 과정을 통해 TanStack Router의 기본적인 작동 방식을 익힐 수 있습니다. 축하합니다!
