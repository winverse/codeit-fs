# 챌린지 해설: 검색 파라미터로 정렬 기능 추가하기

이번 챌린지의 목표는 기존의 검색/필터링 기능에 더하여, URL 검색 파라미터를 사용하여 상품 목록의 정렬 순서를 제어하는 것입니다.

## 1. `validateSearch` 스키마 확장

가장 먼저, 라우트가 `sort`와 `order`라는 새로운 검색 파라미터를 인식하고 검증할 수 있도록 `zod` 스키마를 확장해야 합니다. `sort`와 `order`가 정해진 값(enum)만 갖도록 제한하고, 값이 없을 경우를 대비해 `default()`로 기본값을 설정합니다.

```jsx
// src/routes/products.jsx

// ...
const searchSchema = z.object({
  search: z.string().optional(),
  category: z.string().optional(),
  page: z.number().int().min(1).default(1),
  // 새로운 파라미터 추가
  sort: z.enum(['name', 'price']).default('name'),
  order: z.enum(['asc', 'desc']).default('asc'),
});
// ...
```

## 2. `useSearch`로 정렬 파라미터 가져오기

스키마에 새로운 파라미터를 정의했으므로, `useSearch` 훅의 반환 객체에 `sort`와 `order`가 자동으로 포함됩니다. 이 값들을 변수로 추출하여 컴포넌트 내에서 사용합니다.

```jsx
// src/routes/products.jsx

// ...
function ProductList() {
  // ...
  // sort와 order를 구조 분해 할당으로 가져옵니다.
  const { search, category, page, sort, order } = useSearch({ from: "/products/"});
  // ...
}
```

## 3. 정렬 UI 추가 및 `navigate` 연동

사용자가 정렬 기준을 선택할 수 있도록 `<select>` 드롭다운 메뉴를 UI에 추가합니다. `onChange` 이벤트가 발생하면, `navigate` 함수를 호출하여 URL의 `sort`와 `order` 검색 파라미터를 업데이트합니다. `value`는 `sort-order` 형태로 조합하여 현재 상태를 표시합니다.

```jsx
// src/routes/products.jsx

// ...
  return (
    <div className="page-content">
      {/* ... */}
      <div className="filter-controls">
        {/* ... 기존 input, select ... */}
        
        {/* 정렬 UI 추가 */}
        <select
          className="select-input"
          value={`${sort}-${order}`}
          onChange={(e) => handleSortChange(e.target.value)}

          <option value="name-desc">이름 (내림차순)</option>

          <option value="price-desc">가격 (높은순)</option>
        </select>
      </div>
      {/* ... */}
    </div>
  );
// ...
```

## 4. 정렬 로직 구현

마지막으로, 필터링된 상품 목록(`filteredProducts`)에 `.sort()` 배열 메소드를 적용하여 실제 정렬 로직을 구현합니다. `sort`와 `order` 파라미터 값에 따라 분기 처리합니다.

**중요**: `.sort()`는 원본 배열을 직접 수정(mutate)하므로, `[...filteredProducts]`와 같이 배열을 복사한 후 정렬하는 것이 안전합니다.

```jsx
// src/routes/products.jsx

// ...
function ProductList() {
  // ...
  const filteredProducts = products.filter(/* ... */);

  // 정렬 로직 구현
  const sortedProducts = [...filteredProducts].sort((a, b) => {
    let comparison = 0;
    if (sort === 'price') {
      comparison = a.price - b.price;
    } else { // name
      comparison = a.name.localeCompare(b.name);
    }
    // order가 'desc'이면 순서를 뒤집습니다.
    return order === 'desc' ? -comparison : comparison;
  });

  const paginatedProducts = sortedProducts.slice(/* ... */);
  // ...
}
```

## 핵심 정리

-   **스키마 확장**: `validateSearch`는 검색 파라미터를 추가, 삭제, 수정할 수 있는 유연한 방법을 제공합니다.
-   **상태는 URL에**: 정렬과 같은 UI 상태를 URL 검색 파라미터로 관리하면, 사용자가 현재 상태를 북마크하거나 다른 사람에게 공유할 수 있게 됩니다.
-   **안전한 배열 정렬**: `.sort()`는 원본 배열을 변경시키므로, 의도치 않은 부수 효과(side effect)를 방지하기 위해 항상 배열을 복사(`[...array]`)한 후 사용하는 습관을 들이는 것이 좋습니다.

축하합니다! 이제 검색, 필터링, 정렬, 페이지네이션이 모두 URL 파라미터와 연동되는 완전한 동적 목록 페이지를 구현할 수 있게 되었습니다.
