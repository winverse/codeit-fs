# 챌린지 해설: 레이아웃 라우트 실습

이번 챌린지의 목표는 `_layout.jsx` 파일을 사용하여 특정 경로 그룹에 공통 레이아웃(예: 사이드바)을 적용하는 방법을 익히는 것입니다.

## 1. Admin 레이아웃 생성 (`_layout.jsx`)

가장 중요한 단계는 `src/routes/admin/` 폴더 안에 `_layout.jsx` 파일을 만드는 것입니다. 이 파일은 `/admin` 경로 아래의 모든 자식 라우트들을 감싸는 셸(Shell) 역할을 합니다.

`index.css`에 미리 정의된 `dashboard-layout`, `dashboard-sidebar` 등의 클래스를 사용하여 구조를 만듭니다. 이렇게 하면 스타일과 구조가 분리되어 코드가 훨씬 깔끔해집니다.

```jsx
// src/routes/admin/_layout.jsx
import { createFileRoute, Outlet, Link } from '@tanstack/react-router'

export const Route = createFileRoute('/admin/_layout')({
  component: () => (
    <div className="dashboard-layout">
      <aside className="dashboard-sidebar">
        <h3>Admin</h3>
        <nav className="sidebar-nav">
          <ul>
            <li>
              <Link to="/admin" activeProps={{ className: 'active' }}>
                📊 Overview
              </Link>
            </li>
            <li>
              <Link to="/admin/users" activeProps={{ className: 'active' }}>
                👥 Users
              </Link>
            </li>
            <li>
              <Link to="/admin/reports" activeProps={{ className: 'active' }}>
                📈 Reports
              </Link>
            </li>
          </ul>
        </nav>
      </aside>
      <main className="dashboard-main">
        {/* 자식 라우트들이 여기에 렌더링됩니다 */}
        <Outlet />
      </main>
    </div>
  ),
})
```

## 2. Admin 하위 페이지 생성

레이아웃이 준비되었으니, 그 안에 표시될 실제 페이지들을 만듭니다. `index.jsx`, `users.jsx`, `reports.jsx` 파일을 `src/routes/admin/` 폴더에 각각 생성합니다.

각 파일은 매우 간단합니다. `createFileRoute`로 라우트를 정의하고, `page-content` 클래스를 사용하여 간단한 내용을 보여주는 컴포넌트를 만듭니다.

```jsx
// src/routes/admin/index.jsx
import { createFileRoute } from '@tanstack/react-router'

export const Route = createFileRoute('/admin/')({
  component: () => (
    <div className="page-content">
      <h1>Admin Dashboard</h1>
      <p>Welcome to the admin area. Manage your application from here.</p>
    </div>
  ),
})
```

```jsx
// src/routes/admin/users.jsx
import { createFileRoute } from '@tanstack/react-router'

export const Route = createFileRoute('/admin/users')({
  component: () => (
    <div className="page-content">
      <h1>User Management</h1>
      <p>Here you can manage all the users of your application.</p>
    </div>
  ),
})
```

## 3. 루트 네비게이션 수정

마지막으로, 사용자가 Admin 섹션으로 진입할 수 있도록 `src/routes/__root.jsx`의 메인 네비게이션에 링크를 추가합니다.

```jsx
// src/routes/__root.jsx
import { createRootRoute, Link, Outlet } from "@tanstack/react-router";

export const Route = createRootRoute({
  component: () => (
    <>
      <nav className="root-nav">
        <ul>
          <li>
            <Link to="/" activeProps={{ className: "active" }}>
              🏠 Home
            </Link>
          </li>
          <li>
            <Link to="/about" activeProps={{ className: "active" }}>
              ℹ️ About
            </Link>
          </li>
          <li>
            <Link to="/admin" activeProps={{ className: "active" }}>
              📊 Admin
            </Link>
          </li>
        </ul>
      </nav>
      <main className="root-main">
        <Outlet />
      </main>
    </>
  ),
});
```

## 핵심 정리

- **`_layout.jsx`**: 폴더 내 자식 라우트들의 공통 UI를 정의합니다. URL 경로에는 영향을 주지 않습니다.
- **중첩된 `Outlet`**: `__root.jsx`의 `Outlet` 안에는 `_layout.jsx`이 렌더링되고, `_layout.jsx`의 `Outlet` 안에는 최종 페이지(`index.jsx`, `users.jsx` 등)가 렌더링되는 중첩 구조를 이룹니다.
- **스타일 재사용**: 공통 레이아웃 스타일(`dashboard-layout` 등)을 한 번 정의해두면, 어떤 섹션에서든 재사용하여 일관된 UI를 쉽게 만들 수 있습니다.

축하합니다! 이제 여러 페이지 그룹에 걸쳐 일관된 레이아웃을 적용하는 방법을 마스터했습니다.
