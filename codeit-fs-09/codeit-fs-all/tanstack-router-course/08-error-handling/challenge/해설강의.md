# 챌린지 해설: 글로벌 404 페이지 구현

이번 챌린지의 목표는 TanStack Router에서 존재하지 않는 경로(`404 Not Found`)에 대한 전역적인 에러 처리를 구현하는 것입니다. `NotFoundRoute`와 `NotFoundComponent`를 사용하여 사용자에게 친화적인 404 페이지를 제공합니다.

## 1. `NotFoundRoute` 정의

TanStack Router는 `NotFoundRoute`를 통해 일치하는 라우트가 없을 때 특정 컴포넌트를 렌더링하도록 설정할 수 있습니다. `main.jsx`에서 라우터 인스턴스를 생성할 때 `notFoundRoute` 옵션을 추가합니다.

```jsx
// src/main.jsx
import React from 'react';
import ReactDOM from 'react-dom/client';
import { RouterProvider, createRouter } from '@tanstack/react-router';
import { routeTree } from './routeTree.gen.js';
import './index.css';

// 404 라우트 정의
import { notFoundRoute } from './routes/__root.jsx'; // __root.jsx에서 정의했다고 가정

const router = createRouter({
  routeTree,
  notFoundRoute, // 404 라우트 등록
});

ReactDOM.createRoot(document.getElementById('root')).render(
  <React.StrictMode>
    <RouterProvider router={router} />
  </React.StrictMode>,
);
```

## 2. `NotFoundComponent` 구현

`src/routes/__root.jsx` 파일에 `NotFoundComponent`를 정의합니다. 이 컴포넌트는 `NotFoundRoute`가 활성화될 때 렌더링될 실제 UI입니다. 사용자에게 페이지를 찾을 수 없음을 알리고, 홈으로 돌아갈 수 있는 링크를 제공합니다.

```jsx
// src/routes/__root.jsx
import { createRootRoute, Link, Outlet, NotFoundRoute } from '@tanstack/react-router';

// ... (기존 RootComponent)

// NotFoundComponent 정의
function NotFound() {
  return (
    <div className="page-content" style={{ textAlign: 'center', padding: '5rem 0' }}>
      <h1 style={{ fontSize: '3rem', color: '#dc3545' }}>404</h1>
      <h2 style={{ fontSize: '2rem', color: '#343a40' }}>페이지를 찾을 수 없습니다.</h2>
      <p style={{ fontSize: '1.1rem', color: '#6c757d', marginBottom: '2rem' }}>
        요청하신 페이지가 존재하지 않거나 이동되었을 수 있습니다.
      </p>
      <Link to="/" className="btn">
        홈으로 돌아가기
      </Link>
    </div>
  );
}

// NotFoundRoute 정의
export const notFoundRoute = new NotFoundRoute({
  getParentRoute: () => Route, // __root 라우트의 자식으로 설정
  component: NotFound,
});
```

## 핵심 정리

-   **`NotFoundRoute`**: 일치하는 라우트가 없을 때 특정 컴포넌트를 렌더링하도록 라우터에 등록하는 특별한 라우트입니다.
-   **`NotFoundComponent`**: `NotFoundRoute`에 의해 렌더링되는 실제 404 UI 컴포넌트입니다.
-   **사용자 경험**: 존재하지 않는 페이지에 대한 명확한 피드백을 제공하여 사용자 경험을 개선합니다.
