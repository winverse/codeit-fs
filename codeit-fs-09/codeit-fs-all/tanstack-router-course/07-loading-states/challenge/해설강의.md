# 챌린지 해설: 로딩 상태와 스켈레톤 UI 구현

이번 챌린지의 목표는 TanStack Router의 데이터 로딩 파이프라인을 이해하고, `loader`와 `pendingComponent`를 사용하여 사용자 경험을 향상시키는 것입니다.

## 1. `loader` 함수 구현

가장 먼저, 라우트가 렌더링되기 전에 필요한 데이터를 미리 불러오기 위해 `loader` 함수를 정의합니다. `createFileRoute`의 옵션 객체에 `loader` 키를 추가하고, 비동기 함수를 값으로 전달합니다.

이 함수는 `params` 객체를 인자로 받아, URL에서 `postId`를 추출할 수 있습니다. 이 `postId`를 `fetchPost` 함수에 넘겨주어 특정 게시물의 데이터를 비동기적으로 요청합니다.

```jsx
// src/routes/posts/$postId.jsx

// ...
export const Route = createFileRoute('/posts/$postId')({
  // loader 함수를 추가합니다.
  loader: ({ params }) => fetchPost(params.postId),
  
  component: PostDetail,
  // ...
});
// ...
```

## 2. `pendingComponent` 구현

`loader` 함수가 실행되는 동안(즉, 데이터를 기다리는 동안) 사용자에게 보여줄 UI를 `pendingComponent` 옵션으로 지정합니다. 이는 사용자가 앱이 멈추지 않고 작동하고 있음을 인지하게 하는 중요한 역할을 합니다.

여기서는 `PostSkeleton`이라는 별도의 함수 컴포넌트를 만들어 지정했습니다. 이 컴포넌트는 `src/index.css`에 미리 정의된 `.skeleton` 관련 클래스를 사용하여 콘텐츠의 형태를 미리 보여주는 스켈레톤 UI를 렌더링합니다.

```jsx
// src/routes/posts/$postId.jsx

// ...
export const Route = createFileRoute('/posts/$postId')({
  loader: ({ params }) => fetchPost(params.postId),
  component: PostDetail,
  // pendingComponent를 추가합니다.
  pendingComponent: PostSkeleton,
});

// ...

// 스켈레톤 UI 컴포넌트
function PostSkeleton() {
  return (
    <div className="page-content">
      <div className="skeleton skeleton-title"></div>
      <div className="skeleton skeleton-line"></div>
      <div className="skeleton skeleton-line"></div>
      <div className="skeleton skeleton-line half"></div>
    </div>
  );
}
```

## 3. `useLoaderData`로 데이터 사용

`loader` 함수가 성공적으로 데이터를 가져오면, `PostDetail` 컴포넌트가 렌더링됩니다. 이때 `Route.useLoaderData()` 훅을 사용하여 `loader`가 반환한 데이터를 가져올 수 있습니다. 이 훅은 타입이 완벽하게 추론되므로, `post` 객체의 `title`이나 `body` 속성에 안전하게 접근할 수 있습니다.

```jsx
// src/routes/posts/$postId.jsx

// ...
function PostDetail() {
  // useLoaderData 훅으로 데이터를 가져옵니다.
  const post = Route.useLoaderData();

  return (
    <div className="page-content">
      <h1 className="post-title">{post.title}</h1>
      <p className="post-body">{post.body}</p>
      <Link to="/posts" className="btn" style={{ marginTop: '2rem' }}>
        &larr; 모든 게시물 보기
      </Link>
    </div>
  );
}
// ...
```

## 핵심 정리

-   **`loader`**: 데이터 로딩의 시작점. 라우트 렌더링 전에 실행되어 필요한 데이터를 준비합니다.
-   **`pendingComponent`**: `loader`가 완료될 때까지 사용자에게 보여줄 대기 화면. 스켈레톤 UI, 스피너 등을 사용하여 UX를 개선합니다.
-   **`useLoaderData`**: `loader`가 성공적으로 반환한 데이터를 컴포넌트에서 사용하는 통로입니다.

이 세 가지 핵심 요소를 통해 TanStack Router는 선언적이고 효율적인 데이터 로딩 및 상태 관리 패턴을 제공합니다. 축하합니다!
