# codeit-fs-15 images

Public image assets used by Codeit FS 15 Notion course pages.

- Source course repo remains private.
- Files are organized by course page number.
- Empty page folders are kept with `.gitkeep` so the `01` through `21` page structure stays explicit.
- Mapping file: [manifest.json](./manifest.json)
- Raw URL base: `https://raw.githubusercontent.com/winverse/codeit-fs/main/codeit-fs-15/images/`

## Structure

```text
codeit-fs-15/images/<course-number>/<hash>-<safe-original-name>
```

Do not add screenshots containing secrets, tokens, personal data, student information, or private service screens.
